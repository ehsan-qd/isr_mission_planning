# Runtime visual assets

`battlelab-terrain-v1.png` is a synthetic, non-operational terrain image used by
the mission map. It was generated for this presentation with a navy/yellow
palette and coastal/topographic motifs inspired by public Defence BattleLab
material. It does not depict the real site or operational geography.

Keep the image at this path: the GUI references it as
`/assets/battlelab-terrain-v1.png` and requires no external map service.
